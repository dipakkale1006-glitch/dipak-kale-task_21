# OmniFood — Responsive Food Delivery Landing Page (Task 21)

A responsive single-page landing website demo for **OmniFood**, built using semantic HTML5 and clean modern CSS with full responsive layout handling.

---

## 📋 Project Overview

This project implements all 6 required sections from the specification:
1. **Header + Hero**: Brand circular logo, navigation menu, headline ("GOODBYE JUNK FOOD / HELLO SUPER HEALTHY FOOD"), two CTA buttons (`I'm hungry` and `Show me more`), and dark overlay background image.
2. **How It Works (3 Steps)**: Clean iPhone mockup presentation on the left, 3 numbered circled steps on the right, followed by App Store and Google Play download badges.
3. **Our Cities (4 Cards Grid)**: 4 cards for Lisbon, San Francisco, Berlin, and London with city photography, happy eater counts, chef stats, and Twitter handles.
4. **Testimonials (3 Quotes on Image Background)**: Dark translucent image overlay with quotes, avatars, and customer names.
5. **Pricing Plans (3 Cards)**: Premium ($399/month), Pro ($149/month), and Starter ($19/meal) plan cards with checked and crossed feature lists.
6. **Footer**: Navigation links on the left, social media icons on the right, and copyright notice.

---

## 🚀 How to Run

1. Simply open [`index.html`](index.html) in any modern web browser (Google Chrome, Microsoft Edge, Firefox, etc.).
2. No backend, build step, or external server required!

---

## 📱 Responsive Breakpoints Used

- **Desktop (≥ 1200px)**:
  - Full grid layout
  - 4 columns for Cities section
  - 3 columns for Testimonials and Pricing
  - Side-by-side layout for Phone Mockup and Steps
- **Tablet (≤ 834px)**:
  - Cities adapt to 2-column grid
  - Testimonials stack gracefully
  - Pricing adapts cleanly
  - Phone and steps adapt to a vertical flow
- **Mobile (≤ 390px / 480px)**:
  - Single column fluid layout
  - Collapsible mobile navigation menu toggle with hamburger icon
  - Full-width touch-friendly CTA buttons
  - Zero horizontal overflow scrolling
